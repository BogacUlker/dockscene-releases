# Dockscene downloads

Dockscene is a dock for macOS that changes its apps and widgets with what you're doing, and tells you why.
This repository only holds the signed, notarized downloads; the source is not public.

- **Download:** [Dockscene.dmg](https://github.com/BogacUlker/dockscene-releases/releases/latest/download/Dockscene.dmg) (macOS 14 or later, Apple silicon and Intel)
- **Homebrew:** `brew install --cask bogaculker/tap/dockscene`
- **Website:** https://dockscene.netlify.app
- **Report a problem:** https://dockscene.netlify.app/feedback/ (or Report a Problem… in Dockscene's menu bar menu)

Dockscene updates itself; you don't need to come back here for new versions.
